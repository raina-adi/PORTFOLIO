# Aditya Raina – Portfolio Website

A modern, responsive portfolio website built with HTML5, CSS3, and JavaScript.  
Designed to showcase my skills, projects, and experience as a Full Stack Developer.

---

## 🚀 Features

- Responsive design (desktop, tablet, mobile)
- Modern UI with glassmorphism & moon-themed effects
- Smooth scrolling & scroll animations
- Mobile-friendly hamburger navigation
- Interactive hover effects
- Contact form with validation
- Performance-optimized & SEO-friendly

---

## 📁 Project Structure

```bash
PORTFOLIO/

## 🎨 Customization

You can easily customize the portfolio by updating:

- **Content & text** → `index.html`  
- **Colors & themes** → CSS variables in `styles.css`  
- **Animations & interactions** → `script.js`
